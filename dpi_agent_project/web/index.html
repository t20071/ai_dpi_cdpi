DPI-AI Governance Architecture

          
Architectural principles and security boundaries established by CDPI DPI-AI 2026, DEPA, and NIST AI RMF 1.0.

        


        

          
          

            
🛡️

            
SLM Security Boundary

            
The Small Language Model (SLM) can only propose structured action plans. It has zero direct execution privileges over SQL databases, filesystem, shell, or APIs. The deterministic workflow engine validates and decides all actions.

          


          
          

            
🔐

            
DEPA 5-Gate Consent

            
Every data request is guarded by: Status Check (ACTIVE), Expiry Check (Valid UTC timestamp), Granularity Check (data category allowlist), Purpose Limitation, and simulated SHA-256 integrity verification.

          


          
          

            
⚖️

            
NIST-Inspired Risk Gate

            
Evaluates model confidence (0.80 application threshold), detects ambiguity, checks high-impact workflows, and runs a prototype risk-indicator filter. Unresolved or low-confidence requests escalate to human review.

          


          
          

            
🏛️

            
CDPI "+1 Approach"

            
Extends legacy municipal systems non-invasively by appending transactions to SQLite and separate output CSVs without modifying or disrupting foundational DPI registry infrastructure.
